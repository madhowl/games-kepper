# Changelog v0.2.0

## Дата выпуска: 01.05.2026

### ✨ Новые функции

#### CRUD для жанров
- Создание новых жанров
- Редактирование названия жанра
- Удаление жанра
- Управление через страницу настроек

#### CRUD для издателей
- Создание новых издателей с указанием страны
- Редактирование информации об издателе
- Удаление издателя
- Управление через страницу настроек

#### CRUD для авторов
- Создание новых авторов с биографией
- Редактирование информации об авторе
- Удаление автора
- Управление через страницу настроек

#### Редактирование игр
- Полная форма редактирования игры на отдельной странице
- Редактирование всех полей: название, описание, год, игроки, возраст, время игры, сложность
- Управление связями с жанрами, авторами, издателями
- Кнопка "Редактировать" в карточке игры

#### Фильтрация по жанрам
- Выбор жанра в sidebar для фильтрации дерева игр
- Сброс фильтра при выборе "Все жанры"

### 🔧 Технические изменения

- Добавлен роутинг (@solidjs/router)
- Добавлена страница настроек (`/settings`)
- Добавлена страница редактирования игры (`/game/:id/edit`)
- Добавлена страница добавления игры (`/game/new`)
- Создан компонент TagsSelect для множественного выбора
- Исправлен update_game для обновления связей

### 🚀 Планируется в следующих версиях

- v0.3.0: Импорт/экспорт (JSON, CSV)
- v0.4.0: Улучшение UI (тёмная тема, сортировка, пагинация)
- v1.0.0: Продвинутые функции (схемы компонентов, OCR, PDF)
