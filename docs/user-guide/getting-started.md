# Getting Started

Welcome to Games Keeper! This guide will help you install and set up the application.

## Installation

### Linux (AppImage) - Recommended

1. Download the latest AppImage from the [Releases page](https://github.com/madhowl/games-keeper/releases).
2. Make the AppImage executable:
   ```bash
   chmod +x GamesKeeper.AppImage
   ```
3. Run the AppImage:
   ```bash
   ./GamesKeeper.AppImage
   ```

### Linux (DEB Package)

1. Download the `.deb` package from the [Releases page](https://github.com/madhowl/games-keeper/releases).
2. Install the package:
   ```bash
   sudo dpkg -i GamesKeeper_*.deb
   ```
3. If there are missing dependencies, run:
   ```bash
   sudo apt-get install -f
   ```

### Linux (RPM Package)

1. Download the `.rpm` package from the [Releases page](https://github.com/madhowl/games-keeper/releases).
2. Install the package:
   ```bash
   sudo rpm -i GamesKeeper-*.rpm
   ```

## First Launch

When you first run Games Keeper, you'll see an empty collection. You can start by adding your first game.

### Adding a Game

1. Click the "+" button in the top-right corner.
2. Fill in the game details (title, etc.).
3. Click "Save" to add the game to your collection.
