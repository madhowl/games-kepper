# Features

## Collection Management

- **Hierarchical Structure**: Organize games, expansions, promos, and custom items in a tree view.
- **Add/Edit/Delete**: Easily manage your collection items.
- **Drag & Drop**: Reorder items within the tree.

## Search and Filtering

- **Quick Search**: Find games by title as you type.
- **Genre Filtering**: Filter your collection by genre (planned for v0.2).
- **Publisher Filtering**: Filter by publisher (planned for v0.2).

## Data Persistence

- **SQLite Database**: All data is stored locally in a single `collection.db` file.
- **Automatic Backups**: The database file can be copied for backup.
- **Portable**: Move the `.db` file to another device to transfer your collection.

## User Interface

- **Modern UI**: Built with SolidJS and shadcn-solid components.
- **Responsive Layout**: Works on various screen sizes.
- **Keyboard Navigation**: Full keyboard support for accessibility.
