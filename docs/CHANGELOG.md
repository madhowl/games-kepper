## [0.1.0] - 2026-04-30
### Added
- Basic game collection management (add, edit, delete)
- Hierarchical tree view for games and expansions
- Search functionality
- SQLite database for local storage
- AppImage, DEB, and RPM packaging for Linux
- System tray integration and desktop entry
- Basic UI with SolidJS and shadcn-solid

### Fixed

- Icon display in Linux Mint Cinnamon panel
- Application title in window and taskbar
