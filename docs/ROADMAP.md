# Roadmap

## v0.2.0 (Planned: Q3 2026)
- [ ] Add genres and publishers tables
- [ ] UI for managing genres and publishers
- [ ] Ability to assign genres and publishers to games
- [ ] Filtering by genre and publisher
- [ ] Basic statistics (count by genre, etc.)

## v0.3.0 (Planned: Q4 2026)
- [ ] JSON import/export
- [ ] CSV export
- [ ] Data validation on import
- [ ] Backup and restore functionality

## v0.4.0 (Planned: Q1 2027)
- [ ] Dark/light theme toggle
- [ ] Sorting by various fields (title, year, etc.)
- [ ] Pagination for large collections (optional)
- [ ] Detailed view for games

## v0.5.0 (Planned: Q2 2027)
- [ ] Windows and macOS builds
- [ ] Cross-platform testing
- [ ] Platform-specific packaging improvements

## v1.0.0 (Planned: Q4 2027)
- [ ] Component schema system (custom fields for cards, tokens, etc.)
- [ ] OCR integration via LLM (LM Studio, Ollama, etc.)
- [ ] PDF generator for printing game components
- [ ] Card designer (using Tldraw or similar)
- [ ] Auto-update mechanism

## Long-term Ideas
- [ ] Cloud sync (optional, self-hosted)
- [ ] Mobile companion app
- [ ] Integration with board game APIs (BGG, etc.)
- [ ] Print-and-play generation
