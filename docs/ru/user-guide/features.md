# Возможности

## Управление коллекцией

- **Иерархическая структура**: Организуйте игры, дополнения, промо-материалы и пользовательские элементы в виде дерева.
- **Добавить/Изменить/Удалить**: Легко управляйте элементами вашей коллекции.
- **Перетаскивание**: Изменяйте порядок элементов в дереве.

## Поиск и фильтрация

- **Быстрый поиск**: Находите игры по названию по мере ввода.
- **Фильтрация по жанрам**: Фильтруйте вашу коллекцию по жанрам (планируется в v0.2).
- **Фильтрация по издателям**: Фильтруйте по издателям (планируется в v0.2).

## Сохранение данных

- **База данных SQLite**: Все данные хранятся локально в одном файле `collection.db`.
- **Автоматические резервные копии**: Файл базы данных можно скопировать для резервного копирования.
- **Переносимость**: Переместите файл `.db` на другое устройство, чтобы передать свою коллекцию.

## Пользовательский интерфейс

- **Современный UI**: Построен с использованием SolidJS и shadcn-solid компонентов.
- **Адаптивная верстка**: Работает на различных размерах экрана.
- **Навигация клавиатурой**: Полная поддержка клавиатуры для доступности.
